# 🗺️ Дорожная карта лицензирования ФСТЭК России по ТЗКИ

Практический GRC-проект (симуляция), в рамках которого разработан пошаговый план (Roadmap) приведения ИТ-организации в соответствие с требованиями регуляторов для коммерческого оказания услуг в области технической защиты конфиденциальной информации и персональных данных.

## 🎯 Описание репозитория
В репозитории представлен финальный отчет по учебной практике (в формате `.docx`), содержащий глубокий анализ нормативной базы и пошаговый алгоритм вывода ИТ-бизнеса на соответствие лицензионным требованиям ФСТЭК России.

## 📊 Ключевые разделы работы:
1. **Анализ нормативно-правовой базы:** Сквозной аудит актуальных требований законодательства РФ (*ФЗ-99, ФЗ-149, ФЗ-152, ПП №79, Приказы ФСТЭК №21, №117, №77 и №60*).
2. **Определение лицензионных требований:** Формирование критериев к штату, сертифицированному оборудованию, средствам защиты информации (СЗИ), нормативному фонду и нежилым помещениям.
3. **Моделирование готовности (Gap Analysis):** Оценка дефицита ресурсов компании (кейс с несертифицированным ПО и нехваткой стажа у персонала) с планом устранения несоответствий.
4. **Формирование пакета документов:** Подготовленный проект заявления о предоставлении лицензии по актуальной форме ФСТЭК России.
5. **Симуляция проверок регулятора:** Описание процесса прохождения документарного и выездного аудита ФСТЭК, анализ оснований для отказа.
